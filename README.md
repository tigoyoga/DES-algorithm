# Implementasi DES (Data Encryption Standard) Algorithm

Nama: Tigo S Yoga

Kelas: Keamanan Informasi B  

## Deskripsi 

Kode ini merupakan implementasi dari algoritma **DES (Data Encryption Standard)**, yang digunakan untuk mengenkripsi dan mendekripsi data. DES adalah algoritma simetri yang banyak digunakan untuk keamanan data dalam berbagai aplikasi. Proyek ini ditujukan sebagai tugas untuk mata kuliah *Keamanan Informasi B*.
